# Content

Generated by `bun tools/gen_docs.mjs` from the game data — edit the data, not this file.

## How to add content

Everything below is data. Adding a fighter, move, trainer or map never touches the simulation, renderer or UI.

**A move** — `src/content/moves.js`: `mv(id, name, type, category, tier, power, { anim, sfx, steps: [S(kind, {...})], hitFx, ai: { r: [min, max], kind } })`.
Step kinds: `melee`, `dash`, `proj`, `beam`, `area` (`where: target|self|aim|lead`), `strikes`, `line`, `cone`, `buff`, `barrier`, `wall`, `blink`, `leap`, `grab`, `summon`, `fn` (a function or a name in `SPECIALS`), `fxonly`. Step timing `at` is in ticks after contact. Effects are PMDO particle names from `site/assets/fx/manifest.json`; append `|Type` to recolour a sheet to a type palette. Sounds are `DUN_*` names from the audio manifest.
Tiers set the defaults: Light 10–14 stamina and no cooldown, Medium 18–26 and 0.3–0.6 s, Heavy 30–40 and 1.2–2.0 s, Signature 45–55 and 3–4 s, Ultimate from the meter.

**A fighter** — add its SpriteCollab id to `tools/recipes.py` (sprite build), then `D(id, { role, kit: [4 move ids], ult, trav?, passive?, radius, mega?, serpent? })` in `src/content/species.js` and add it to `ROSTER[env]`. Stats and types come from Showdown data automatically.
**A traversal** — `TRAVERSALS` in `src/game/traversal.js` (`start`, `update`, optional `locomote`, `replacesDodge`, `ai`). Point a fighter at it with `trav`.
**A map** — an entry in `src/content/maps.js` (`size`, `play` rect, `obstacles`, `feature`, `music`, `ambience`), its painting in `inputs/arena-backgrounds/` (processed by `tools/build_assets.py maps`) and its id in `MAPS_BY_ENV`. Interactive features live in `src/game/features.js`.
**A trainer** — `src/content/trainers.js`: name, title, portrait, colour, a 3-Pokémon team per environment (from that environment's roster) and an intro line; add the id to `TRAINER_ORDER`.
After any content change run `bun tools/validate.mjs` (every reference and every move in the real sim), then `bun tools/build.mjs`.
